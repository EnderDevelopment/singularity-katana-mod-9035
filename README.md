# Singularity Katana Mod

A powerful katana with unique abilities for Minecraft 1.20.1

## Features

- Custom weapon: Singularity Katana
- Special ability: Singularity Slash

## Requirements

- Java 17
- Forge 47.x
- Minecraft 1.20.1

## Installation

1. Download the mod JAR file.
2. Place it in your Minecraft mods folder.
3. Launch Minecraft with Forge.

## Usage

1. Craft or obtain the Singularity Katana.
2. Use the Singularity Slash ability by right-clicking while holding the katana.

## Configuration

The mod includes a configuration file where you can adjust various settings. The configuration file is located in the config folder of your Minecraft instance.
